# strongdog_prox

This is a test project to demonstrate the injection of games from `cards-data.js` using `strongdog.com` as the base URL.

This project is a modified version of the `4sp-max/logged-in/games.html` file, adapted to use `strongdog.com` for all game and image assets.

## How to use

To avoid CORS issues, it's recommended to serve these files from a web server. You can use a service like `raw.githack.com` by providing the URL to the `index.html` file in this repository, or by enabling GitHub Pages for this repository.
